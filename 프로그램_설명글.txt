■ 프로그램 개요
--------------------------------------------------------------------------------
· 프로그램명 : 안심 디자인 (Beta)
· 배포 형태   : 단일 파일 실행형 (ImgEditor.html)
· 실행 환경   : 인터넷 익스플로러를 제외한 모던 웹 브라우저 (Edge, Chrome, Whale 등)
· 라이선스   : 비영리 공공 업무 지원 프리웨어 (무료 배포)


■ 이런 분들께 추천합니다
--------------------------------------------------------------------------------
1. 망분리 내부망에서 외부 디자인 사이트(미리캔버스, 캔바 등) 접속이 차단되어 
   파워포인트나 한글(HWP)로 어렵게 홍보물을 제작하시던 실무자
2. 행사 포스터, 카드뉴스, 현수막, 표창장, 안내문 제작이 잦은 담당자
3. 보도자료나 공문 배포 전 사진 속 얼굴이나 개인정보 마스킹 작업이 번거로우셨던 분
4. 관리자 권한(보안 승인)이 없어 별도 설치형 그래픽 프로그램을 깔지 못하시는 분


■ 주요 핵심 기능
--------------------------------------------------------------------------------
1. 100% 오프라인 단독 구동 (망분리 완벽 준수)
   - 외부 서버, 클라우드, CDN과의 통신이 일체 없는 순수 단일 HTML 파일입니다.
   - 작업 중인 이미지, 텍스트, 개인정보 등 모든 데이터는 내 PC 메모리 안에서만 처리되므로 기술적으로 정보 유출이 원천 차단됩니다.

2. 완전 무설치 (Zero-Install)
   - 보안 프로그램 승인이나 관리자 권한 설치 과정이 전혀 필요 없습니다.
   - 첨부된 'ImgEditor.html' 파일을 다운로드하여 더블클릭하면 즉시 실행됩니다.

3. 공공 실무 맞춤형 기본 템플릿 23종 탑재
   - 정책 홍보 포스터, 카드뉴스, 현수막 배너, 인쇄용 공문 서식
   - 우수직원 표창장, 생일 축하 카드, 안내 배너 등 실무에 자주 쓰는 템플릿 기본 내장
   - 캔버스 규격(A4, 현수막, 인스타 카드뉴스 등) 원클릭 프리셋 지원

4. 저작권 걱정 없는 기본 에셋 무제한 무료 제공
   - 자체 생성된 고화질 사진 162종, 귀여운 동물/공공 일러스트, 폰트, 도형 완비
   - 프로그램에 내장된 기본 에셋으로 제작한 결과물은 출처 표기 의무 없이 대외 공문, 홍보물, 인쇄물에 전면 자유 배포 가능합니다.
     (※ 단, 사용자가 PC에서 직접 불러온 외부 파일은 해당 원작자 규정 준수 필요)

5. 개인정보 점검 및 자동 마스킹 보조
   - 주민등록번호, 전화번호, 계좌번호 등 텍스트 패턴 자동 탐지
   - 사진 속 인물 얼굴 자동 인식 및 모자이크/블러 처리 보조 기능 제공

6. 다양한 포맷 저장 및 프로젝트 보관
   - 고해상도 PNG, JPG, PDF 인쇄용 내보내기 지원
   - 작업 내용을 프로젝트 파일(.json)로 저장하여 언제든 다시 열어 수정 가능


■ 실행 및 사용 방법
--------------------------------------------------------------------------------
1. 본 게시글에 첨부된 [ ImgEditor.html ] 파일을 PC의 원하는 폴더(바탕화면 등)에 다운로드합니다.
2. 다운로드한 파일을 더블클릭하여 브라우저(Edge, Chrome 등)로 엽니다.
3. 좌측 [템플릿] 메뉴에서 원하는 디자인을 선택하거나 빈 화면에서 자유롭게 편집합니다.
4. 작업 완료 후 우측 상단 [내보내기] 버튼을 눌러 이미지(PNG/JPG) 또는 PDF로 저장합니다.


■ 이용 시 유의사항 (필독)
--------------------------------------------------------------------------------
1. 개인정보 최종 육안 검토 의무
   - 자동 얼굴 인식 및 개인정보 마스킹 기능은 실무자의 작업을 돕는 '보조 수단'입니다.
