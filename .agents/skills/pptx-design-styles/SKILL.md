# PPTX Modern Design Styles Skill

## 1. Anti-Generic AI Design Rules (탈(脫) AI 디자인 원칙)
AI가 만든 슬라이드가 촌스럽고 인위적으로 느껴지는 5대 원인을 엄격히 금지합니다:

1. **가짜 UI 위젯 남발 금지 (No Fake UI Clutter)**
   - 의미 없는 맥OS 창 닫기 버튼(●●●), 가짜 슬라이더, 가짜 컬러 박스 등 겉치레 그래픽 요소를 억지로 넣지 않습니다.
   - 슬라이드의 본질은 '주장과 근거의 명확한 전달'입니다.

2. **카드 매트릭스 병 탈피 (Break the 3-4 Card Matrix)**
   - 똑같은 크기의 둥근 사각형 3~4개를 나란히 놓고 위에 아이콘 하나, 제목, 본문 두 줄 넣는 전형적인 'AI 카드 나열' 레이아웃을 금지합니다.
   - 비대칭 그리드(Asymmetric Grid, 65:35 또는 70:30), 전면 타이포그래피, 대형 단일 비주얼 중심 배치를 우선합니다.

3. **무지개 배지 금지 (Strict 2-3 Color Palette)**
   - 한 슬라이드에 파랑, 보라, 초록, 주황, 핑크를 동시에 쓰지 않습니다.
   - **지배색(Dominant 60%) + 보조색(Secondary 30%) + 액센트 1개(Signal Accent 10%)** 법칙을 철저히 준수합니다.

4. **단순 주제 명사 금지 ➔ 액션 타이틀 의무화 (Action Titles)**
   - '단위 경제학', '아키텍처 개요' 같은 건조한 명사형 제목 대신, 해당 슬라이드가 증명하고자 하는 핵심 명제/결론을 헤드라인으로 작성합니다.
   - 예: "온프레미스 단독 구동으로 데이터 주권 규제를 100% 충족합니다."

5. **과감한 여백과 대비 (Negative Space & Typographic Scale)**
   - 슬라이드를 빈틈없이 채우려 하지 않습니다. 시선이 집중될 수 있도록 여백(Negative Space)을 40% 이상 확보합니다.
   - 헤드라인(44~64pt)과 본문(14~18pt)의 압도적인 크기 대비로 시선 이동 경로를 명확히 합니다.

## 2. 주요 대표 디자인 스타일

### ① Swiss International Style (스위스 인터내셔널 스타일)
- **분위기**: 권위 있는, 정돈된, 타임리스, 최고급 컨설팅/금융/기관
- **배경**: 순백색(`#FFFFFF`) 또는 소프트 웜 화이트(`#FAFAFA`)
- **색상**: 딥 잉크 블랙(`#111111`) + 스위스 시그널 레드(`#E8000D`) 단 1개의 포인트
- **레이아웃**: 엄격한 5분할/12분할 그리드, 좌측 수직 레드 룰 바, 굵은 산세리프 타이포, 장식 배제

### ② Editorial Magazine Style (에디토리얼 매거진 스타일)
- **분위기**: 지적이고 세련된 에세이, 인터뷰, 럭셔리 브랜드, 심층 분석
- **배경**: 페이퍼 크림(`#F7F5F0`) 또는 딥 올리브/차콜
- **색상**: 잉크 블랙 + 올리브/버건디 포인트
- **레이아웃**: 대형 세리프 헤드라인, 2단 신문형 칼럼 본문, 넉넉한 자간과 행간

### ③ Strategic Minimal (맥킨지 / 전략 컨설팅 미니멀)
- **분위기**: 중역/이사회 보고, 핵심 명제 중심, MECE 논리 구조
- **배경**: 플래티넘 그레이(`#F8FAFC`) 또는 딥 네이비
- **색상**: 네이비 블루(`#0A192F`) + 로열 블루(`#1D4ED8`)
- **레이아웃**: 명확한 상단 액션 타이틀 + 하단 1개 또는 2개의 비대칭 데이터 전시물(Exhibit)

### ④ Clean Keynote (스티브 잡스 스타일 순수 키노트)
- **분위기**: 압도적 집중력, 신제품 론칭, 비전 제시
- **배경**: 칠흑 같은 옵시디언 블랙(`#000000`)
- **색상**: 크리스프 화이트 텍스트 + 단 1개의 네온 또는 실버 포인트
- **레이아웃**: 거대한 단 1개의 수치 또는 1줄의 선언문, 잔가지 설명 완전 배제
